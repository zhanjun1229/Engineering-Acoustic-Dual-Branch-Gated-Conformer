# 实现范围与代码组织

版本：0.1.2。

## 提供的实现

- Acoustic156：MFCC39、LFCC39、CQCC39 和 GFCC39 的拼接特征。
- IAPD26：时域、频域及周期相关特征，包含归一化与分段。
- 双分支独立 Conformer、样本级 Softmax Gate 和二分类器。
- MIMII 文件发现、标签、分层文件级划分、段级缓存和 DataLoader。
- 监督训练、Dev EER 早停、权重保存、文件级评估和结果导出。
- 四种机器和三种噪声组成的12组独立域内实验。

## 与参考实现的一致性

模型结构、参数名、特征公式、数据划分、训练和评估计算保留参考实现的定义。文件系统设置通过命令行指定：数据根目录必填，预提取特征目录可选，输出目录默认为 `./results`。

`tests/original_fingerprints.json` 记录参考脚本的 SHA-256、原始 AST 指纹和忽略文档字符串后的执行 AST 指纹。测试逐项核对71个函数、类和常量。发布文档与注释的修改不改变计算表达式或实验参数。

源代码按功能拆分，模型层名称保留，因此 state_dict 键不因模块拆分而变化。所有入口均调用同一训练实现：`conformer-train`、`python -m dual_conformer_gate` 和 `python train.py`。

## 发布范围

本仓库提供主方法源码、实验默认参数、安装说明和本地检查工具，不包含原始音频、预提取特征、训练权重、完整实验结果、超参数搜索记录或其他方法的对比实验实现。

测试验证实现一致性和合成输入下的关键行为，没有完成整套 MIMII 训练或论文结果逐项复现。依赖版本为本地验证环境的直接依赖清单，验证细节见 [VALIDATION.md](VALIDATION.md)。

## 使用注意事项

指标公式、完成结果跳过规则、特征失败处理及缓存复用行为以 README 和实现为准。修改实验或特征参数后，应使用独立输出目录。正式实验应核对实际成功读取和评估的文件。
